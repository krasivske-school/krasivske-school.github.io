# Сайт Красівського ліцею — нотатки для Claude

Сайт-візитка сільського закладу освіти: інформація для батьків, документи для відділу освіти, новини.
Без розкладу, без особистих кабінетів. Живий сайт: https://krasivske-school.github.io

## Користувач
- Пише українською (іноді російською) — відповідай українською, простими словами, без жаргону.
- Не програміст. Сайт веде сам, один. Інструкції — покроково, з назвами кнопок.
- Наприкінці кожної правки нагадуй, як опублікувати: GitHub Desktop → **Fetch origin → Pull origin → Commit to main → Push origin**.
- На ПК немає git у PowerShell — комітить і пушить сам користувач через GitHub Desktop. Ти не комітиш.

## Стек
- Astro 5, статичний сайт. `npm run dev` (порт 4321, конфіг preview — `.claude/launch.json`, ім'я `site`), `npx astro build`.
- GitHub: організація `krasivske-school`, репозиторій `krasivske-school.github.io`, гілка `main`.
  Публікація — `.github/workflows/deploy.yml` (GitHub Actions → Pages), сайт з кореня домену.
- Адмінка: **Sveltia CMS** на `/admin/` (`public/admin/index.html`, `public/admin/config.yml`), вхід токеном GitHub.
  Pages CMS більше не використовується (`.pages.yml` видалено). Адмінка комітить напряму в `main` —
  тому локальна копія часто відстає; перед правками нагадуй про Pull.
- Шрифт Manrope (@fontsource), у стеку першим стоїть e-Ukraine (файлів немає).

## Де що
- `src/data/site.json` — назва, підпис, логотип, цифри на головній, контакти, підтримка сайту, гарячі лінії, адміністрація.
- `src/data/documents.json` — список документів (`file` має пріоритет над `url`) + категорії.
- `src/content/news/*.md` — новини (`title`, `date`, `cover`, `gallery` список фото, `photosFolder`, `draft`).
- `src/content/pages/*.md` — текстові сторінки (`section`: pro-nas | batkam | dokumenty | novyny; `group`, `order`).
- `src/lib/nav.ts` — розділи меню. `src/layouts/Base.astro` — шапка (логотип, меню, перемикач теми) і підвал.
- `src/styles/global.css` — токени кольорів, світла/темна тема (`data-theme` + prefers-color-scheme), стилі `.prose`, `.org` (схема структури), `.plan` (таблиця плану булінгу).
- `astro.config.mjs` — rehype-плагіни: префікс base для `/uploads/`, зовнішні посилання і файли — у новій вкладці.
- `scripts/import-old-site.mjs` — одноразовий імпорт зі старого сайту krasine_school.klasna.com (уже виконано).
- `public/uploads/` — фото і файли; `shkola.jpg` (фото будівлі), `logo-shkola.jpg` (мініатюра 200×200 для шапки).

## Прийняті рішення (не міняти без запиту)
- Стиль gov.ua / Дія / Мрія: чорне на білому, сірі картки з великим радіусом, чорні кнопки-пігулки, пастельний градієнт.
- Головна — «плитки-бенто» (листопад 2026): сіре тло, білі плитки (назва + фото, 4 плитки швидкого доступу);
  один акцент — фіолетовий (`--violet`, `--violet-soft`, `--violet-ink` у `global.css`).
- Посилання в контактах — колір тексту з тонким підкресленням (`.clink`), не сині. Біля e-mail — `CopyButton`.
- Назва закладу ніде не захардкоджена: «ліцей» лише в `site.json` (через рік заклад може стати гімназією).
  Розділ «Про нас» = `/pro-nas/`. Село тепер **Красівське** (історичні згадки «Красіне» в історії лишаються).
- Філія лишилась одна — **Веселівська** (с. Веселе); Златоустівської більше немає. Окремого розділу про філію на сайті немає. Розкладу немає.
- Схема «Структура та органи управління» — HTML у `struktura.md`, не картинка.
- Сторінка «Протидія булінгу»: інструкція, документи, гарячі лінії текстом, план 2021/22 у `<details>` (план застарів — чекаємо новий).
- Тексти-картинки замінювати текстом. Не підтягувати зображення з i.ibb.co (повільно в Україні).

## Обмеження і безпека
- Репозиторій публічний: ніяких персональних даних учнів, паспортів, медичних даних, заяв. Історія git зберігає видалене.
- Відео — тільки посиланням на YouTube. Фото через адмінку стискаються до 1920 px WebP.
- Ліміт GitHub Pages — 1 ГБ на сайт; зараз ~4 МБ.

## Що ще не зроблено
- Фото в старих новинах і на деяких сторінках досі з krasine_school.klasna.com та i.ibb.co — перенести в `public/uploads/`.
- Документи — посилання на Google Drive двох акаунтів; план — перенести як PDF (питати дозволу на скачування).
- «Вступ до 1 класу» — текст про 2022–2023 н. р.; «Домашнє насильство» — лише картинки.
- «Території обслуговування» — текстом за рішенням № 581 (2021); скани рішення ще з i.ibb.co (у `<details>`), перенести в uploads.
- Застарілі документи: освітня програма і мережа класів (2021–22), кошторис (2023), план заходів з булінгу (2021/22).
