# Сайт Красівського ліцею

Сайт-візитка ліцею: інформація для батьків, документи для відділу освіти і новини.
Зроблено на [Astro](https://astro.build), публікується на GitHub Pages, редагується через [Sveltia CMS](https://sveltiacms.app).

## Як редагувати

Адмінка: **https://krasivske-school.github.io/admin/**

**Перший вхід (один раз на комп'ютері):**
1. Натисніть «Вхід за допомогою токена доступу» (Sign In with Token).
2. У вікні є посилання на GitHub для створення токена — відкрийте його.
3. Repository access → Only select repositories → `krasivske-school.github.io`.
   Permissions → Contents: **Read and write**. Термін дії — до 1 року.
4. Generate token → скопіюйте токен → вставте в адмінку.
   Якщо GitHub попросить схвалити токен для організації — схваліть у налаштуваннях організації (Settings → Personal access tokens → Pending requests).

**Далі:**
- **Новини** → «Створити» → заголовок, дата, головне фото, **Фотогалерея** (виділіть або перетягніть одразу всі фото) → текст → «Зберегти».
  Фото автоматично зменшуються до 1920 px і стискаються.
- **Документи і контакти → Документи** → додайте документ: назва, категорія, рік і файл (PDF/Word) або посилання.
- **Документи і контакти → Контакти і загальна інформація** — назва закладу, адреса, телефони, адміністрація, цифри на головній.

Після збереження сайт оновлюється сам приблизно за 1–2 хвилини.

## Де що лежить

| Що | Файл |
|---|---|
| Новини | `src/content/news/*.md` |
| Текстові сторінки | `src/content/pages/*.md` |
| Список документів | `src/data/documents.json` |
| Контакти, адміністрація, цифри | `src/data/site.json` |
| Фото і PDF | `public/uploads/` |
| Стилі | `src/styles/global.css` |

## Для розробника

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # збірка в dist/
npm run import     # імпорт сторінок і 30 новин зі старого сайту (наявні файли не перезаписує)
npm run import -- --news=100 --force
```

## Публікація на GitHub Pages

1. Створіть репозиторій на GitHub і завантажте туди цю папку (наприклад, через GitHub Desktop).
2. У репозиторії: **Settings → Pages → Source: GitHub Actions**.
3. Кожне оновлення гілки `main` публікує сайт автоматично (`.github/workflows/deploy.yml`).

Репозиторій `krasivskyi-lyceum` в особистому акаунті дає адресу
`https://<логін>.github.io/krasivskyi-lyceum/`. Фото з адмінки (`/uploads/...`) працюють і в підпапці —
шлях виправляється під час збірки (`astro.config.mjs`).

## Що ще треба зробити

- Фото й картинки досі завантажуються зі старого сайту і з i.ibb.co. Перед закриттям старого сайту
  їх треба перенести в `public/uploads/`.
- Документи — посилання на Google Drive. Краще завантажити PDF у `public/uploads/`.
- Оновити застарілі документи: освітня програма і мережа класів (2021–2022), кошторис (2023).
- «Вступ до 1 класу» містить текст про 2022–2023 н.р. — оновити.
- «Території обслуговування», «Домашнє насильство», «Структура» — тільки картинки, бажано текстом.
- Додати e-mail і Facebook у `src/data/site.json`, оновити кількість учнів і вчителів.
- Шрифт: за наявності файлів e-Ukraine (брендбук Дії) додайте їх — стиль уже на нього розрахований,
  зараз використовується схожий Manrope.
