Сюди кладіть папки з фото для новин.

1. На комп'ютері створіть папку, наприклад 2026-11-10-osinnii-bal (латиницею, без пробілів).
2. Покладіть у неї фото (jpg, png, webp).
3. На github.com відкрийте цю папку (public/uploads/galereia) -> Add file -> Upload files
   і перетягніть туди всю папку -> Commit changes.
4. В адмінці в новині в полі «Папка з фото» напишіть назву папки: 2026-11-10-osinnii-bal
